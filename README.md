# Elite Concierge Service - Landing Page

Landing page professionnelle pour Elite Concierge Service - Services de conciergerie haut de gamme pour la diaspora congolaise.

## 🚀 Démarrage Rapide

### Prérequis
- Node.js 18+ 
- npm ou yarn

### Installation

```bash
npm install
```

### Développement

```bash
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000) dans votre navigateur.

### Production

```bash
npm run build
npm start
```

## 📋 Structure du Projet

```
src/
├── app/
│   ├── layout.tsx          # Layout principal avec métadonnées
│   ├── page.tsx            # Page d'accueil (landing page)
│   └── globals.css         # Styles globaux
├── components/
│   ├── Header.tsx          # Barre de navigation
│   ├── Footer.tsx          # Pied de page
│   ├── HeroSection.tsx     # Section héros
│   ├── ServiceCard.tsx     # Carte de service
│   ├── PricingCard.tsx     # Carte de tarification
│   ├── TestimonialCard.tsx # Carte de témoignage
│   └── Button.tsx          # Composant bouton
```

## 🎨 Design & Personnalisation

- **Couleurs**: Or (gold) et Bleu marine (navy-900) comme couleurs principales
- **Framework**: Next.js 14 + React 18
- **Styles**: Tailwind CSS avec configuration personnalisée
- **Animations**: Framer Motion pour les animations fluides

## 📱 Sections de la Landing Page

1. **Hero Section** - Introduction avec CTA principal
2. **Services** - 6 services premium avec détails
3. **Pricing** - 3 plans d'abonnement (100$, 150$, 300$)
4. **Testimonials** - Avis clients
5. **Contact** - Formulaires et liens WhatsApp/Email
6. **Footer** - Navigation secondaire et réseaux sociaux
