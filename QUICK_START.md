# 🚀 QUICK START - Démarrer en 5 minutes

## 1. Installation (1 minute)

```bash
cd /Users/adsgmdr/projects/EliteConciergeService
npm install
```

## 2. Lancer le serveur (30 secondes)

```bash
npm run dev
```

Ouvrir: **http://localhost:3000**

Vous devriez voir votre landing page! 🎉

---

## 3. Personnaliser le Contenu (2 minutes)

Ouvrir: **`src/lib/constants.ts`**

Remplacer:
- `name: 'Elite Concierge Service'` → Votre nom
- `email: 'contact@eliteconcierge.cd'` → Votre email
- `whatsapp: '+243 829 431 311'` → Votre numéro

Voir: **`CONTENT_EDITING_GUIDE.md`** pour plus de détails

---

## 4. Ajouter Vos Photos (1 minute)

1. Créer dossier: `public/images/`
2. Y mettre: `ceo.jpg` (votre photo)
3. Ouvrir `src/components/HeroSection.tsx`
4. Remplacer la section photo

Voir: **`IMAGE_INTEGRATION_GUIDE.md`** pour les détails

## 🆘 Problèmes?

### Le port 3000 est déjà utilisé?


### Le site ne met pas à jour après changements?
```bash

# Puis:
npm run dev
```

### Dépendances manquantes?
